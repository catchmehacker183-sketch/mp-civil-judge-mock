# MP Civil Judge Prelims Mock

## Current paper engine
- Total: 150 questions
- Law: 110 questions (weighted-random distribution by subject)
- General Knowledge: 20 fixed
- Computer Knowledge: 10 fixed
- English Knowledge: 10 fixed
- Duration: 120 minutes
- All questions are globally shuffled.
- Daily selection is deterministic for a date, so refreshing does not create a different paper mid-day.

## Question bank model
Every question should have:
- unique id
- subject
- topic
- difficulty
- question
- 4 options
- correct answer index
- explanation
- legal reference where applicable

## Important
The current project includes 150 starter bank items so the 150-question engine works. For genuinely different daily mocks, expand the bank substantially. The architecture is designed for thousands of questions.
